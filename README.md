#  Pollify App

A real-time polling application built using **Node.js, Express, MongoDB, and EJS**.  
Users can create polls, vote on options, and view live results with charts.

##  Features

- Create custom polls
- Yes/No, True/False, and Multiple Choice polls
- Real-time vote tracking
- Session-based duplicate vote prevention
- Poll expiration system (timer-based)
- Result visualization (winner detection)
- MongoDB Atlas database integration
- Session storage using MongoDB (connect-mongo)

---

##  Tech Stack

- **Backend:** Node.js, Express.js
- **Frontend:** EJS, HTML, CSS
- **Database:** MongoDB Atlas
- **ODM:** Mongoose
- **Session Storage:** connect-mongo
- **Other Tools:** express-session, cors, dotenv, ejs-mate
